Wall texture PNGs go here.

Filenames the game expects:
  wall_kennel.png
  wall_garden.png
  wall_cavern.png
  wall_park.png
  wall_ship.png

Each should be a seamless tileable image; the loader downscales to
64x64 ImageData at runtime so source resolution doesn't matter much
(256–1024 px is fine). PNG only.
