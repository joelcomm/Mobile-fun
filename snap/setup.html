One-time Google Drive setup (≈5 min)
  1. In Google Drive, create a folder for the event and open it. Copy the folder ID from the URL (the part after /folders/).
  2. Go to script.google.com → New project.
  3. Paste the contents of apps-script.gs (in this folder) and set FOLDER_ID to your folder ID.
  4. Click Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone. Authorize when prompted.
  5. Copy the Web app URL and paste it in the field above.
  6. Generate the QR, print it, and put it where attendees can scan it. Done.
